# 精算と精算履歴

`/settlement` で未精算支出を確認して精算を開始する。金額と対象は開始時に固定され、相手の確認で完了する。開始者は取り下げ、相手は差し戻しを選べる。`/settlements` には確認待ちと完了の履歴が表示される。

## Sub-features

- `settle-balance` ホームと `/settlement` の `未精算差額` が未精算支出の立て替え額の合計と一致する。
- `settle-blocked-partner` パートナー未参加だと `パートナーが参加してから精算できます` が出て `精算する` が無効。
- `settle-blocked-draft` 下書きがあると `確定または削除してから精算してください` が出て精算できない。
- `settle-start` `精算する` で対象を固定し、確認待ちならホームへ戻る。ホームに `確認待ち` の枠が表示され、開始者・確認者で案内文が変わる。
- `settle-confirm` 開始者以外が `確認して完了` を押すと完了し、精算履歴へ移る。
- `settle-release` 開始者は `取り下げる`、相手は `差し戻す` を確認ダイアログ経由で選べる。対象支出は未精算に戻る。
- `settle-zero` 差額0円は確認待ちを経由せず、その場で完了する。
- `settle-cancel` 精算履歴では確認待ち行から `/settlement` を開く。取り消せるのはサーバーが許可した直近の完了行だけ。
- `settle-cap` 未精算が多いと古い順に上限件数だけ対象になり、その旨の注意が出る。

## How to get to it (user POV)

- ホーム(`/`)の `未精算差額` または `確認待ち` の枠(`/settlement` へのリンク)。
- ヘッダーのメニューから「精算」。
- ホーム下部の「精算履歴」リンク → `/settlements`。
- URL 直打ち `http://localhost:3100/settlement`、`http://localhost:3100/settlements`。

## Driving it with playwright-cli

Preconditions:

- `$V login` 済み。確認・差し戻しの検証には2人が参加した世帯が必要。
- マーカー付きの確定済み未精算支出が1件以上ある。
- 2人目の操作では、その人のブラウザー状態を `$V pw state-save` で保存して切り替える。

- **精算を開始する。** `$V pw goto http://localhost:3100/settlement`。見出し `精算`、`未精算差額`、`精算の対象(N件)` とマーカー付き支出を確認する。`$V pw fill "#memo" "$MARK 精算"` → `$V pw click "getByRole('button', { name: '精算する' })"`。確認依頼が送られた場合は `/` に戻り、ホームに `確認待ち` と金額が表示される。
- **両者のホームを見る。** 開始者側は `{partner}さんの確認待ちです`、確認者側は `あなたの確認待ちです。内容を確認してください` と表示される。枠に閉じる操作はない。
- **相手が確認する。** 確認者の状態に切り替えて `/settlement` を開く。`確認待ちの精算`、開始時の金額、`N件の支出を対象に {starter} が開始`、固定された対象一覧を確認する。開始後に別の支出を追加している場合は次回分の案内も出る。`$V pw click "getByRole('button', { name: '確認して完了' })"`。`/settlements` に移り、行の状態が完了になる。
- **開始者が取り下げる。** 新しい未精算支出で開始し、開始者の `/settlement` から `取り下げる` を押す。ダイアログの `この精算を取り下げます。対象の支出は未精算に戻ります。よろしいですか?` を確認して accept。ホームに戻り、未精算差額が復活する。相手へのお知らせは出ない。
- **相手が差し戻す。** 別の未精算支出で開始し、確認者が `/settlement` の `差し戻す` を押す。`この精算を差し戻します。対象の支出は未精算に戻ります。よろしいですか?` を確認して accept。開始者のホームに `精算({amount})を差し戻しました` のお知らせが出て、「閉じる」で消せる。
- **差額0円。** 貸し借りが相殺する支出を用意して `精算する`。確認待ち画面を挟まず `/settlements` に移る。
- **取り消す。** `/settlements` で `確認待ち` 行に取り消しボタンが無く、`canCancel` が許可する直近の完了行にだけ `この精算を取り消す` があることを確認する。押して confirm → `$V pw dialog-accept`。ホームの未精算差額が戻る。
- **Proof。** `E=$($V evidence settlement)` に開始前 `/settlement`、双方のホーム、確認待ち画面、完了履歴、取り下げ・差し戻し後の snapshot / screenshot を保存する。

## Gotchas

- 確認者は支払う側・受け取る側ではなく、精算を開始していないメンバー。
- 確認待ち対象の金額と品目は編集・削除できない。分類だけ変更できる。
- 開始後に登録した支出は固定対象に含まれず、次回の精算に回る。
- 差し戻し後の支出は未精算に戻る。アプリ外で送金済みでも自動では記録されない。
- 取り消しは直近の完了行だけ。確認待ちがある間は、前回の完了分も取り消せない。
